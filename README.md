# ContractComparison
Comparison of General Chinese Contracts with OCR  Pytorch

## 结果展示

本仓库是本地 PyTorch 脚本，**不能在浏览器中运行 OCR**。静态走查页根据 README、源码与 `test/` 素材整理问题、管线、可见结果与限制：

https://unstoppablecurry.github.io/ContractComparison/

页面由 GitHub Actions 从 `docs/` 发布。仓库没有提供准确率、客户、生产或性能指标，展示页也不会编造这些数字。
